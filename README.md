# miniMusic
一个功能最精简的 Android 本地音乐播放器，零第三方依赖（不依赖 AndroidX/Compose），单 Activity + 传统 View 代码式 UI。
## 版本记录

| 版本 | 变更                                                         |
| ---- | ------------------------------------------------------------ |
| v1.0 | 初始发布：本地音频扫描、播放控制、SeekBar 进度条             |
| v1.1 | 新增全屏滚动歌词（LRC 解析 + 自定义视图 + 动画）、界面美化（卡片化控制条、主色高亮、深色主题）、字体层次优化 |
| v1.2 | 歌词自动换行与横屏自适应、歌词页内嵌播放控件                 |
| v1.3 | 主界面曲目列表改为**编号式深色播放列表**（序号列 + 标题 + 歌手·格式，极细分割线、当前行橙红序号/纯白加粗标题/深红褐高亮带、ViewHolder 复用、按压反馈），整体配色深色化（页面背景、底部控制条、状态栏统一深色家族；主色保留蓝色作控制色，橙色仅表「当前播放」）。收尾：ActionBar 背景覆盖为深色 surface（消除 Theme.Material 默认取 colorPrimary 导致的亮蓝顶栏）、当前行高亮带透明度 0x66→0x80 加强、无扩展名时不再渲染悬空的「歌手 · 」分隔符 |
| v1.4 | ①修复歌词页内切歌时顶部歌曲名不同步（`playAt` 中统一刷新歌曲信息）；②歌词同屏行数 3→**6 行**（前 2 / 当前 / 后 3，距离越远越淡），竖屏横屏字号与行距相应收紧；③列表**去掉序号列与文件格式**（仅标题 + 歌手）；④点击列表项播放时**自动进入歌词页**（上一首/下一首/自动切歌不强行跳转）；⑤修复四个控制键因默认 minWidth=88dp 被挤压而文字截断（改为等宽平分 + 清零最小宽高）；⑥主界面「歌词」键与歌词页「列表」键构成 **歌词/列表 切换对** |
| v1.5 | ①移除歌词页底部的「点击歌词区域退出」提示文字（画面更干净）。**功能保留**：退出回调本就挂在撑满中部的 `contentArea`（`isClickable + setOnClickListener`）而非提示文字上，删文字不影响退出，且中部点击区随之下移扩展。顺带清理因此孤立的三处资源（`lyric_exit_hint` / `lyric_hint_size` / `lyric_hint_margin`）。②**隐藏顶部标题栏**（原显示应用名「极简音乐」）：`AppTheme` 加 `windowActionBar=false` + `windowNoTitle=true`，并删除孤立的 `actionBarStyle` 与 `AppTheme.ActionBar` 样式。注意应用名未动（manifest 的 `android:label` 仍是 `@string/app_name`），桌面图标名不受影响；隐藏后内容区多出约 56dp 竖向空间。③**新增应用启动图标**（基于「暴富喵」原图）：5 档密度 legacy `ic_launcher.png` + 5 档自适应前景 `ic_launcher_foreground.png` + `mipmap-anydpi-v26/ic_launcher.xml`（`<adaptive-icon>`，背景纯白），manifest 增加 `android:icon`。④**歌曲列表为有歌词的歌曲显示「词」字胶囊标签**：行结构改为三元素 `[标题 weight=1][词胶囊][歌手]`，标记置于标题**之后**以保证歌名左边缘恒定对齐；有无歌词复用播放时的 `findLrcFile()` 判定并按路径缓存（不引入目录列举 `listFiles()`，规避 Android 11+ 分区存储风险），无歌词时置 `GONE` 不占位 |
